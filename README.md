# plaits-navigator

travelers guide for finding your voice: a one-page reference for the mutable instruments plaits macro-oscillator, firmware 1.2. all 24 models with what every knob and the aux output do, model navigation (including the yellow bank), trig / level / lpg, held-button settings and LED codes, with diagrams.

live page: https://mellotom.github.io/plaits-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

compiled from the mutable instruments plaits manual, the 1.2 firmware notes (https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/) and the open-source plaits firmware. not affiliated with mutable instruments.
